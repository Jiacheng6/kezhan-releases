## 本次更新

- 作业页关闭或软件重启后，可重新打开并恢复已保存的答案和简答草稿。
- 恢复前核对作业和题目，题目顺序变化也能匹配；信息不全时保留记录并提示核对。
- 简答修改先保存草稿，页面填写失败不再误报成功。
- 平台确认提交成功后才标记完成，批量提交分别报告结果，避免连续点击重复操作。

0.4.1 用户启动时会收到新版提示，也可手动点击「检查更新」。

**0.3.x / 0.4.0 用户请先在软件中手动点击“检查更新”，安装一次 0.4.2。之后启动会自动提醒。**

下载不会停止当前任务；确认安装后保存进度、备份数据并打开安装程序。普通退出不会自动安装更新。免安装版使用内置安装入口时会切换为安装版，继续读取同一用户的数据。

账号登录、课程清单、设置和进度保存在本机 `%APPDATA%\XuexitongAssistant`，发布包不包含开发者个人数据。平台登录失效时仍需重新登录。

软件不会因启动或检查更新而开始课程任务。AI 网页版需要登录自己的账号，额度与验证限制以平台提示为准。
