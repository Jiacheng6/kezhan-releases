# 学习通助手 Windows 软件包

[下载最新版本](https://github.com/Jiacheng6/xuexitong-assistant-releases/releases/latest)

支持 Windows 10 / 11 x64，需要 Microsoft Edge。安装包文件名以 `Setup.exe` 结束；免安装版本为 `win-x64.zip`，完整解压后打开「学习通助手.exe」。

0.3.0 开始支持内置更新：检查更新 → 下载新版 → 保存并安装。首次从旧版升级，需要手动安装一次 0.3.0 或更高版本。安装前会提示停止任务并备份数据，普通关闭软件不会自动安装更新。

登录状态、课程清单、课程选择和进度保存在本机 Windows 用户的数据目录。更新后自动读取已有课程；平台登录失效时仍需重新登录。免安装版使用内置安装入口时会提示切换为安装版，并使用原数据。

这里仅提供软件包、更新清单、增量下载数据和校验文件。不包含开发者登录状态、课程记录、运行日志或测试账号数据。
