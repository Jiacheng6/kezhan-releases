- 三栏工作台集中展示选课、进度和开始／停止，设置与工具默认收起。

0.4.1 及以上用户启动时会收到新版提示，也可在软件中手动检查更新。较早版本请手动检查更新或下载新版。

下载不会停止当前任务；确认安装后保存进度、备份数据并打开安装程序。普通退出不会自动安装更新。免安装版使用内置安装入口时会切换为安装版，继续读取同一用户的数据。

账号登录、课程清单、设置和进度保存在本机 Windows 用户数据目录，发布包不包含开发者个人数据。平台登录失效时仍需重新登录。

软件不会因启动或检查更新而开始课程任务。AI 网页版需要登录自己的账号，额度与验证限制以平台提示为准。
